# 排错与已知限制

## 常见问题

| 现象 | 处置 |
|---|---|
| 弹窗报「无法连接 Ollama」 | 确认 `ollama serve` 在运行，或 `base_url` 正确 |
| 弹窗报「模型不存在」 | `ollama pull <模型名>` |
| 弹窗报「云端鉴权失败」 | 检查 `cloud.api_key` 是否正确、是否过期 |
| 弹窗报「云端模型不存在」 | 检查服务商要求的基础地址与模型名；是否包含 `/v1` 取决于服务商 |
| 勾选「联网查询」立刻弹回 | 检查是否开启严格离线、是否配置了检索密钥。在「设置…」中填写并保存后立即生效；手工编辑配置或新增环境变量后需重启 |
| 解释没走联网 | 确认 `web_search.enabled=true` 且已配 key；译文标签本就不检索 |
| 译文带出思考过程 | 本地 Ollama 请求已设置 `think:false`；云端模型是否输出思考内容取决于服务商与模型设置 |
| 觉得翻译慢 | 看 `app.log` 中预热是否完成；换 8B 模型，或改用云端模型 |
| 改了配置没生效 | 手工编辑后需重启；确认没有旧实例在跑（单实例机制下再次启动不会加载新代码） |
| 设置窗口打不开 | 若被划词弹窗挡住，设置窗已置顶；必要时重启 |

日志位置：源码运行在项目目录 `app.log`；打包版在 `%APPDATA%\huayi\app.log`。

## 已知限制

- 目标窗口为**管理员权限**时取词无效。
- 剪贴板兜底只还原文本格式（CF_UNICODETEXT），富格式（带排版的 Excel/Word 单元格）丢失。
- 传统控制台（`cmd` 窗口）不支持兜底（Ctrl+C 是中断信号）；Windows Terminal 可以。
- 键盘选区（Shift+方向键）不浮图标，需用热键。
- 部分 Electron/Java 应用 UIA 取词延迟较高或取不到（JetBrains 需热键兜底）；浏览器首次查询慢几百 ms 属正常。
- 「本地模型」不等于「离线」。离线使用需启用 `offline: true`，并按 [CONFIG.md](CONFIG.md) 关闭 Ollama 云功能；该开关不能控制其它程序的外部连接。

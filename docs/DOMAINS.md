# 领域适配（学科模式）与个人知识库

只靠通用大模型翻译专业文献，常出现三类问题：术语译法前后不一、不是学科惯用译法、长尾概念完全译错。划译的「领域」机制把你的专业知识注入每次请求，按生效层级分为四种，可任意组合：

| 能力 | 解决什么 | 形态 |
|---|---|---|
| **领域说明** | 文体与惯例（如"药名用通用名"） | 一段追加到提示词的文字 |
| **术语表** | 术语一致性与惯用译法（**强制**遵守） | CSV 表：`原文,译文,备注` |
| **知识库检索（RAG）** | 长尾术语、私人资料 | 指向你的文献文件夹，划词时自动检索相关片段 |
| **翻译记忆** | 个人译法风格积累 | 你确认过的句对，相似句自动作为参考 |

## 快速上手：切换学科

1. 弹窗头部有「学科」下拉框（通用 / 电池/能源 / …），或托盘右键 →「学科」子菜单；
2. 切换后**下一次请求**即生效（弹窗底部状态行会显示当前学科），已生成的结果不会重译；
3. 「通用」= 不附加任何领域信息。

内置了「电池/能源」示例领域（含 39 条术语表），作为自建领域的参考样例——不需要可直接在设置里停用或删除。

## 自建一个领域（如"医学"）

托盘右键 →「设置…」→「领域与知识库」：

1. 点「新建」，输入名称（如 `医学`）；
2. **领域说明**：写一段给模型的领域要求，例如：
   > 这是临床医学文献。药名使用中文通用名（不使用商品名）；解剖学名词遵循《人体解剖学名词》译法；保留标准缩写并在首次出现时附全称。
3. **术语表**：点「新建空表」生成 CSV 后直接编辑（见下节）；
4. 保存。之后弹窗和托盘的学科菜单里就会出现「医学」。

领域配置保存在 `config.json` 的 `domains` 字段（也可手工编辑，见 [CONFIG.md](CONFIG.md)）。

## 术语表（glossary）

- 位置：数据目录下 `glossaries/<领域id>.csv`（源码运行=项目目录；打包版=`%APPDATA%\huayi\`）；
- 格式：每行 `原文,译文,备注(可省略)`，UTF-8 编码（带 BOM，Excel 可直接编辑），`#` 开头为注释行；
- 匹配：翻译前扫描划选文本，**命中的术语**连同指定译法注入提示词并要求严格遵守（未命中的不注入，不浪费上下文）；
- 同一原文多次出现时，**后面的行生效**——在表尾追加即可覆盖修正；
- 改表**即时生效**（按文件修改时间热加载），无需重启。

示例：

```csv
# 临床常用术语
heart failure,心力衰竭
HF,心力衰竭,缩写首次出现时标注
MI,心肌梗死,勿译"心肌梗塞"
```

## 知识库检索（RAG）

把你的文献、笔记文件夹变成翻译/解释的外部知识：

1. 设置 → 选中领域 → 知识库区「添加目录」，指向存放资料的文件夹；
2. 勾选「启用知识库」；点「重建索引」（后台执行，完成后显示文件/片段数）；
3. 支持 `txt / md / csv / json / pdf / docx`，单文件上限 20MB；
4. 默认**解释**时检索注入最相关的 3 个片段（附来源路径）；勾选「翻译时也检索」后译文标签同样生效（略增延迟）；
5. 索引按文件修改时间**增量更新**：启动与修改目录后自动刷新，平时几乎无开销；
6. 索引数据存于数据目录 `kb_index/`，删除领域不会动你的原始文件。

## 翻译记忆（TM）

1. 译文生成后，点弹窗底部的「存为记忆」；
2. 在弹出的对话框里**先修正译文**再保存（推荐只存自己校对过的句子）；
3. 之后翻译相似句子时，自动把最相似的 3 条句对作为参考示例注入（相似度过低则不注入）；
4. 记忆按领域隔离存储在 `tm/<领域id>.jsonl`，「通用」模式也有自己的记忆；总开关在设置里，单领域可在设置里清空。

## 提示词组装顺序

切换领域后，system prompt 按以下顺序拼接（各段存在才拼，均有长度预算防止撑爆上下文）：

```
基础提示词 → 领域说明 → 术语对照(命中) → 知识库片段(检索) → 参考译例(TM) → 联网检索
```

## 常见问题

- **切了学科没变化？** 切换只影响下一次请求；点「重试」重新生成即可。
- **术语没生效？** 检查术语原文是否真的在划选文本中出现（匹配按**英文词边界**进行：formation 不会命中 information，deintercalation 也不会误配 intercalation；中文按包含匹配）；检查 CSV 是否 UTF-8 编码。
- **知识库检索结果不相关？** BM25 是词面检索，中文按二字组合匹配；文档越规整效果越好。可以点「重建索引」排除旧文件影响。
- **隐私**：领域说明、术语表、知识库片段、翻译记忆都会作为提示词发给所配置的模型后端（本地或云端），与普通翻译的数据流向一致；严格离线模式下仍然全部本地。索引会自动跳过 `config.json`（含 API Key）、术语表、翻译记忆与索引目录本身，即使把程序目录设为知识库，密钥也不会被检索注入。

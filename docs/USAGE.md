# 使用说明

## 触发与取词

- **拖选 / 双击 / 三击**：选区右下角浮出「译」图标，点击后弹窗显示译文。
- `Ctrl+Alt+Shift+T`：取当前选中文字，直接打开「译文」标签（UIA 取不到时走剪贴板兜底）。
- `Ctrl+Alt+Shift+E`：同上，打开「解释」标签。
- `Ctrl+Alt+Shift+I`：呼出「输入翻译」页，自己打字翻译。

程序默认启动时不抢焦点；浮标仅在 UIA 返回非空选中文本时显示。

## 弹窗

弹窗里有四个标签：**译文 / 解释 / 追问 / 输入翻译**。

- **译文**：选中文字后立即请求。
- **解释**：首次切到该标签时才请求。
- **追问**：切到该标签会自动固定窗口，可以多行输入——`Shift+Enter` 或 `Alt+Enter` 换行，`Enter` 或「发送」提交；支持连续问答与失败重试。
- **输入翻译**：输入/粘贴文本，选目标语种（默认「自动：中→英 / 其他→中」，也可手输如「粤语」），`Ctrl+Enter` 或点「翻译」。切到该标签会自动固定窗口；点 `×` 关闭，或取消固定后按 `Esc`。翻译后该文本即成为当前讨论对象，可继续切到「解释 / 追问」。

其它：

- **学科切换**：弹窗头部「学科」下拉框（或托盘 →「学科」子菜单），切换领域后下一次请求生效，详见 [DOMAINS.md](DOMAINS.md)。
- **存为记忆**：译文 / 输入翻译标签底部按钮——修正译文后存入翻译记忆，以后翻译相似句子自动作为参考。
- **显示在最前**：保留结果窗口，点击其他应用和按 `Esc` 都不会关闭；点 `×` 关闭。
- **拖动**：按住窗口顶部「拖动这里移动窗口」移动；各标签下均可拖动。
- **缩放**：拖动右下角手柄调整宽高；同一次运行中重新打开窗口会保留调整后的大小。
- **停止**：译文、解释、追问、输入翻译均可停止，保留已生成内容。停止追问后可立即发新问题；其余可重新生成。
- **关闭**：`Esc` 或点击弹窗外关闭未固定的弹窗，并取消进行中的请求。

## 追问的上下文

追问会结合当前原文、已有译文 / 解释以及最近若干轮对话。使用**输入翻译**时，该输入文本及其译文也会进入上下文。

## 托盘

托盘右键菜单：**设置、输入翻译、暂停 / 恢复监听、联网查询、开机自启动、打开配置文件、退出**。

- 「设置…」：选择本地 / 云端 / 混合模型、填 API Key、开联网检索或严格离线。
- 「暂停监听」：临时停止划词触发。
- 「联网查询」：解释 / 追问是否先联网检索（见 [CONFIG.md](CONFIG.md)）。
- 「开机自启动」：勾选 / 取消，无需管理员权限。

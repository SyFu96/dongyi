# 本地模型与搜索独立配置

追问和输入翻译可分别选择本地模型或云端模型；搜索服务与模型后端独立。

- 设置 → 模型：分别选择追问模型、输入翻译模型。「本地」使用已配置的本机 Ollama 模型；「云端」调用配置的云端模型 API。
- 设置 → 联网搜索：总开关控制所有检索，解释、追问和输入翻译另有独立开关。输入翻译默认关闭检索，开启后将搜索结果作为术语和背景参考，仍按选定目标语言只输出译文。
- 弹窗中的「本地 / 云端」只切换回答模型，不控制搜索；检索是否执行由设置中的搜索开关决定。

本地模型无需 DeepSeek 等云端模型 key；联网搜索仍使用现有 Ollama 搜索 key（也可从 `OLLAMA_API_KEY` 环境变量读取）。[Ollama 官方文档](https://docs.ollama.com/capabilities/web-search)说明搜索 key 可通过免费账户创建。此配置不调用云端模型接口，不承诺搜索服务永久无额度限制。

旧配置兼容：解释和追问沿用现有搜索行为；输入翻译需显式开启搜索。严格离线时所有检索均关闭。搜索失败仍用所选模型回答，不自动切换云端模型。

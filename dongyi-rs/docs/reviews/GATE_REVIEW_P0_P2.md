## 阻断项

1. **B1／P1：配置保存写错对象。** `src-tauri/src/lib.rs:36–42` 先将当前 `guard` 写入磁盘，再把内存替换为 `new_cfg`。首次保存后重启会恢复旧配置，连续保存也始终落后一版。要求：持同一把锁完成新配置写盘与内存更新，写盘失败时保留原内存值；验证保存→重新读取，包括未知字段保留和写盘失败。

2. **B2／P2：浮标及弹窗缺少屏幕边界限制。** `src-tauri/src/orchestrator.rs:275、323、346` 直接使用选区右下角或光标偏移定位，没有选择所在显示器并 clamp 到可用区域。屏幕右侧、底部划选时，浮标或弹窗可能落到屏幕外。直接使用物理坐标本身不判错；问题是未结合窗口实际物理尺寸与显示器边界。要求：落实边界定位，验证四边与混合缩放双屏。

3. **B3／P2：浮标没有自动隐藏，防抖忽略配置。** `src-tauri/src/orchestrator.rs:278` 显示浮标后没有超时逻辑；配置中的 `icon_timeout_s` 未被消费。`:180` 将防抖硬编码为 150ms，忽略 `debounce_ms`。与执行文档的 3s 自动隐藏及 Python 基线行为不符。要求：按配置执行，新浮标重置计时，旧计时不得隐藏新候选。

4. **B4／P2：关闭没有使待完成请求失效，结果消费没有复查。** `src-tauri/src/orchestrator.rs:242` 的 `close_all` 只隐藏窗口和清空候选，不取消防抖或使捕获失效；`:258` 消费结果时不检查有效性。可构造：拖选后立即 Esc，150ms 防抖仍会提交取词；或捕获尚未完成时关闭，结果随后重新显示浮标/弹窗。`crates/dongyi-capture/src/lib.rs:716` 仅静默 submit 更新 latest，显式请求不使旧静默请求失效；`:744` 显式路径不复查提交时的目标窗口。要求：关闭和新交互统一管理请求有效性，在发键及 UI 消费前复查；覆盖关闭后迟到结果、热键覆盖静默请求、排队时切窗。部分问题也存在于 Python 基线；逐条移植不等于可以通过本阶段有效性审查。

5. **B5／P2：缺少里程碑要求的跨应用实测证据。** 当前 README 仍是模板，未找到 P0～P2 验收报告或应用矩阵。`cargo test` 中 capture、trigger 和编排均为 0 个测试，无法证明“全应用取词实测通过”。要求：记录应用/版本、UIA 或剪贴板路径、操作、预期、实际结果；至少覆盖浏览器、文本编辑器、PDF 阅读器（含默认白名单 sioyek）、终端排除、富格式剪贴板静默跳过、剪贴板恢复、拖选/双击/热键、防误触及混合缩放双屏。不要求现在验证 P3 流式或 P6 打包指标。

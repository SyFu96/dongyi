# 划词重译与联网翻译

日期：2026-10-21。

译文上方新增翻译方式选择和“重新翻译”。无需重新划词，直接使用当前原文。

- 本地模型：直接调用配置的 Ollama 模型。
- 联网搜索 · 本地模型：用现有 Ollama 搜索 key 检索术语/背景，再由本地模型翻译当前原文；译文下显示实际参考的搜索来源。
- 联网翻译 · 云端模型：直接调用已配置的云端模型，需要云端模型 key，可能计费；此模式本身不附带网络搜索。

切换方式会立即重译，“重新翻译”沿用当前方式。本次选择只保留在当前选区会话，不修改全局模型配置；新选区仍按原先配置选择初始后端。

切换领域后，当前译文或解释立即按新领域重算，原文不变，隐藏的译文/解释页签在下次打开时重算。领域名称也加入模型提示，不再依赖领域备注必须非空。长原文限高滚动，避免挤掉翻译按钮和结果区。

英文段落被模型原样返回时，显示“尚未完成翻译”与重译提示，保留返回内容供查看，不登记为可保存的完成译文。检测仅覆盖明显原样返回的英文句段，忽略空白、大小写和标点差异；短术语和明确要求译成英文的请求不受此判断影响。它不能判断所有翻译质量问题。

重译和切领域先取消旧流、撤销旧请求号、检索代次、来源和记忆配对，防止旧回答迟到覆盖新结果。主动搜索翻译遵守严格离线设置；缺 key、检索失败或无可用资料时明确报错，不静默冒充联网成功。其他功能原有搜索失败回退行为保留。

验证：核心库与编排层定向测试（共 16 项），覆盖语向、原样返回、短术语/手动目标、三种模式/离线检查、旧请求与记忆配对作废、领域搜索词及原有页签/追问重试；前端构建与组件渲染检查通过，检查方式选择、忙时切换、无选区禁用、可见错误和来源列表。布局在 460×320 的窗口容器中检查。没有用用户云端 key 执行计费模型测试。

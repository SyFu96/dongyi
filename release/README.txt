懂译 v0.1.1 — Windows x64
=========================

怎么用
------
1. 把整个 dongyi 文件夹解压到任意位置（不要只拿走 dongyi.exe，_internal 目录必须一起）。
2. 双击 dongyi.exe。
3. 在支持取词的应用里选中文字，点击选区旁的「译」图标；也可按 Ctrl+Alt+Shift+T 热键取词；托盘右键 →「设置…」配置模型。

本版功能（首个以「懂译」发布的完整功能版）
------------------------------------------
- 划词浮标 → 弹窗「译文 / 解释 / 追问 / 输入翻译」四个标签
- 深色 / 浅色双主题（可跟随系统），新设计的弹窗、设置与托盘外观
- 学科切换（内置电池/能源示例），强制术语表、个人知识库（PDF/DOCX/Markdown/TXT）、翻译记忆
- 本地 Ollama 与任意 OpenAI 兼容云端，可按标签混合；一键「严格离线」
- 解释/追问可联网检索（可选，需自己的 API key）

取词说明
--------
- 拖选取词基于 UI Automation，在多数现代应用可用；少数自绘界面应用读不到选区。
- 默认对明确支持的阅读器 **sioyek** 启用受控剪贴板兜底（可在设置里关闭或增补白名单）：
  自动恢复你的剪贴板原状；剪贴板里是图片、文件、富格式时自动跳过，不会覆盖原内容——
  此时热键取词始终可用。本程序不承诺所有应用都出现浮标。

模型配置
--------
- 本地翻译：需自行安装 Ollama 并下载模型（例如 qwen3-vl:30b-a3b-instruct）。
- 云端翻译：在「设置…」里选择「云端 API」，填写 OpenAI 兼容的地址 / 模型 / API Key。
- 想保证不外发：在「设置…」里勾选「严格离线」。

数据位置
--------
- 配置与日志：%APPDATA%\dongyi\
- 退出程序：托盘右键 → 退出。
